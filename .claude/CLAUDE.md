# graphify
- **graphify** (`.claude/skills/graphify/SKILL.md`) - any input to knowledge graph. Trigger: `/graphify`
When the user types `/graphify`: only the skill's markdown is installed here (`.claude/skills/graphify/`); the graphify CLI itself is not installed on this machine and `graphify-out/` was never built (see `CLAUDE.md`'s graphify section). Read the skill's instructions, but expect its commands to fail until the binary and the graph exist.
